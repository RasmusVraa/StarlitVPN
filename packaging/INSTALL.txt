StarlitVPN
==========

1. Распакуйте архив в любую папку. Эту папку потом не удаляйте.

2. Chrome / Edge / Brave
   Вставьте в адресную строку:  chrome://extensions
   (Edge: edge://extensions)
   Включите «Режим разработчика».
   «Загрузить распакованное расширение» → выберите эту папку
   (в ней лежит файл manifest.json).

3. Firefox
   about:debugging#/runtime/this-firefox
   Load Temporary Add-on → файл manifest.json из этой папки.
   В обычном Firefox дополнение пропадает после перезапуска.

4. Нажмите иконку StarlitVPN. Если появится «Включить StarlitVPN» —
   нажмите кнопку: откроется вкладка установки.
   Запустите StarlitVPN-setup.exe. Если Windows покажет предупреждение —
   «Подробнее» → «Выполнить в любом случае».
   Когда появится окно «StarlitVPN установлен», вернитесь в браузер.
   Если расширение всё ещё просит включить ядро — на chrome://extensions
   нажмите «Обновить» у StarlitVPN.

5. Откройте личный кабинет и добавьте подписку:
   https://cabinet.starlit-moon.ru

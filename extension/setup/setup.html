Включить StarlitVPN

Нажмите кнопку — браузер скачает установщик. Если спросит про опасный файл, нажмите «Оставить» / «Keep».

  1. Разрешите скачивание файла StarlitVPN-setup.exe
  2. Если Windows покажет предупреждение: Подробнее → Выполнить в любом случае
  3. Дождитесь окна «StarlitVPN установлен»
  4. Вернитесь сюда — эта страница закроет установку сама

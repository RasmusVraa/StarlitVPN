# Тексты для витрин

## Кратко
Клиент Starlit для Chrome и Firefox на ядре Xray. Подписки только с sub.starlit-moon.ru.

## Полное описание
StarlitVPN подключает браузер к вашей подписке Starlit.

- Протоколы VLESS, Reality, Hysteria2 и другие, которые отдаёт панель
- Импорт только с домена sub.starlit-moon.ru
- Локальное ядро Xray через native host
- Проксируется только трафик браузера

Установка: распакуйте пакет, выполните `native-host/install.ps1`, загрузите папку `extension` как unpacked-расширение и перезапустите браузер.

## Категория
Productivity / Privacy

## Скриншоты
